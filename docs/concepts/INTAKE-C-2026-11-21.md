# Intake C: harness philosophy (hypothesis, 2026-11-21)

Status: hypothesis. Rigid order steps 1 (name) and 2 (concept records); nothing specced, built or measured.
Source: `INTAKE-2026-11-21.md` section C. Index of record: `catalog/nomenclature.jsonl` and `catalog/concepts.jsonl` (the inbox `catalog/inbox/context-zpncyv.jsonl` was merged into them); this file is the prose their `see` values point to (`INTAKE-C-2026-11-21.md#c1` to `#c9`).
Labels: lowercase `c1` to `c9` below are items of this intake, not the concepts C1 to C17 of `CATALOG.md`. In prose they are written "intake item cN" where a bare label could be confused.
Common thread: fewer model turns where the answer is determined by data. The model says what in words; the harness does how.
No existing concept is superseded: each item below adds a claim the existing records do not make. Existing ids are linked, not copied.

<a id="c1"></a>
## c1 Collector, command as query (pckaas, cchwyx; concept vifitn)
Why: a host (files, repo, machine) is data. Exploring it turn by turn (list, read, re-read) costs requests and invites repeats (fault fhjphb).
One scripted command that returns what the step needs replaces that. Near: inventory with captures (wmzdrt), select then fetch (klsrrk), host file tools (rabacn), graft (uvgdji, a small model builds the payload; a collector is code, not a model).

<a id="c2"></a>
## c2 Intent route (mqecrr; concept nlavpp)
Why: small models mis-generate params. They state intent in words; policy tags pick a fixed command. Near: flow router (ilyhcw), semantic-entry handler (umepbc), tags (uwgdqn), seam contracts (ijihvc). Distinct: those route a flow or pick turns; this routes one call to one fixed command.

<a id="c3"></a>
## c3 Result shape (rfeeue; concept xagosf)
Why: the output is the output. Follow-on formatting is set by command type and single-responsibility params, and only the pertinent part returns (names, not metadata). Near: klsrrk, vtpcxq, ijihvc (return payload shape), argument summary (jgyfik, the profile side). Distinct: shaping the live result, per command type.

<a id="c4"></a>
## c4 Command alias (yijgei; concept wrqmen)
Why: a terse label is cheaper and safer for a small model than full syntax; the alias holds the params and the tidy-up, so the model neither writes nor remembers them. Near: handles (swhuvh, qvmztp), ambiguous markers (hzzgju). Fault: made-up handle (hqvmzk).

<a id="c5"></a>
## c5 Bucket (hbjdyo; concept jjzxso)
Why: state of an undetermined target is collected by fixed queries into keyed deferred results (as handles already are: results by id); a goal fans out into buckets. Near: concern queue (zsfqyi), stems (gxxncg, a goal branches), handles, has/has-not view (remjvg).

<a id="c6"></a>
## c6 Partial turn (yhaayl; concept qgqixs)
Why: a turn pre-filled as sentences with labeled, data-bound parts lets a router pick references by fuzzy position, not by generated text. "Slot" here means turn fields (vxjisn), not the UI slot (lbhvob). Near: turn templates (lyayzn), semantic entries (ocqhtx), warp materialization (qblgkn), ambiguous markers (hzzgju).

<a id="c7"></a>
## c7 Passive marker (fjcvwq; concept glxylm)
Why: picked or important items get an external label beside the turns (zero request bytes, flows invariant 1); on a clash the most recent label picks the variant, which survives drift and renames and cuts hallucinated references. Near: tags (uwgdqn), identity by checksum (zlnvtx, renames of files), hzzgju (the in-prefix twin). Fault: hqvmzk.

<a id="c8"></a>
## c8 Helper depth (ujstnh; concept ckauzr)
Why: a helper that writes markers and tags to steer another model is flow alteration (tampqj, drbhtd) with a rule added: only the harness calls helpers, never a helper another helper, so cost and audit stay flat (pppezv, one cent per operation).

<a id="c9"></a>
## c9 Further principles (derived, kept few)
- Cheapest actor first (anjxau; concept udwgqu): code, then query, then small model, then main model; follows from intake items c1, c2, c8 and one cent per operation.
- Scaffold degree (zjcwvx; concept hgvkrr): the aid in intake items c2 to c8 is a per-model setting, recorded; strong models may need none. Follows from per-model records (concepts are per model) and influence mode (thfqaz).
